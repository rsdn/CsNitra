## Deviations
- **Design decision (user):** `Recoverable = false` removed from `ParseContextScope` (commit 89040dc). Rationale: any rule must be recoverable, including context-scoped ones (raw interpolated string literals); a broken parse tree is acceptable. `ParseContextScope` bodies now parse with default (recoverable) options, so S1–S5 repair candidates are available inside them (not just S6). The C1 strict-region gate in `RecoveryEngine.Generate` is kept for other `Recoverable:false` sources (e.g. `RecoveryRule`). This supersedes the "strict context ⇒ hard-fail" premise (plan §3.9) and narrows the C1 "strict ⇒ only S6" contract to non-ContextScope strict regions.
- 1.5: (a) Converted 7 `Regular`/`Verbatim` `AssertFails` → `AssertRecoversWithEnd` (beyond the 11 raw inputs) and deleted the unused `AssertFails` helper in `InterpolatedStringTests.cs`. These 7 were failing at the 1.3.2 baseline (pre-existing 1.3.2 S6 regression, verified by stashing) and reach EOF, so `AssertFails` was wrong; conversion was required to meet the "CSharpGrammarTests 0 failed" verification. Overlaps 1.3.3.
